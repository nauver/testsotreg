# Testimonial infographic

## Local preview

Open `index.html` directly, or run:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

Upload `index.html` to the repository root and enable Pages from the main branch.

## Accessibility

The page is designed towards WCAG 2.2 AA: semantic landmarks, keyboard-visible focus, skip link, responsive reflow, reduced-motion support, forced-colour support, hidden decorative elements, descriptive links and non-colour cues. Automated and manual checks should still be run before publication.
